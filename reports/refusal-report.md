## 拒答双向测量

当前阈值：最高检索分 < **1.000** 就拒答

| 方向 | 数值 | 含义 |
|---|---|---|
| 库外问题被挡住 | **66.7%**（8/12）| 越高越安全：少硬答 |
| 库内问题被误拒 | **0.0%**（0/36）| 越低越有用：少漏答 |

> **两个数必须一起看。** 把阈值调到无穷大，拒答正确率 100%、误伤率也 100%——
> 那不是安全，那是系统完全不工作。

## 阈值扫描（取舍曲线）

候选阈值**从实际分数分布里推导**（相邻最高分的中点），
所以无论 BM25 分数是什么量级，曲线都会落在有信息的位置。

**你要选的是「两个数都还能接受」的那个点。**

| 阈值 | 库外拒答率 | 库内误伤率 |
|---|---|---|
| 0.000 | 66.7% | 0.0% |
| 2.921 | 66.7% | 5.6% |
| 3.429 | 66.7% | 16.7% |
| 3.773 | 91.7% | 25.0% |
| 4.133 | 91.7% | 36.1% |
| 5.124 | 91.7% | 50.0% |
| 6.117 | 100.0% | 55.6% |
| 8.661 | 100.0% | 66.7% |
| 9.934 | 100.0% | 80.6% |
| 13.494 | 100.0% | 91.7% |

> 阈值越大 → 越倾向于拒答。库外拒答率会升到 100%，但库内误伤率也会升。
> **没有免费的午餐**，这个点由你定（写在 `rag/boundary.py`）。
