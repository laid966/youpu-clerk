# 33 · 部署手册（G4 闸门：公网可访问）

> 目标：评审期（约 12/10-14）作品在公网稳定可访问，HTTPS，含演示 60 秒路径。
> **最长杆是 ICP 备案（首次 7-20 天）——服务器和域名要今天就买，备案今天就开始走。**

## 0. 架构（刻意简单：一个盒子跑全部）

```
用户浏览器 ──HTTPS──► Caddy(自动证书) ──反代──► uvicorn(clerk.server:app, 127.0.0.1:8100)
                                                    └── SQLite(data/clerk.db, 每日备份)
DeepSeek API ◄──话术生成（无 key 自动降级 TemplateJudge，站点不会挂）
```

不需要 Docker、不需要数据库服务、不需要 CDN。单机单进程，评委打开就能玩。

| 项 | 建议 | 参考成本 |

⚠️ **备案期间域名不能解析到服务器提供 web 服务**——所以顺序是：买 → 备案 → 期间继续本地开发 → 通过后一天内部署上线。

## 2. 部署步骤（备案通过后，约 30 分钟）

```bash
# 服务器上（Ubuntu 22.04/24.04）
sudo apt update && sudo apt install -y python3.12 python3.12-venv caddy git

# 代码
git clone <你的仓库> /opt/clerk && cd /opt/clerk
python3.12 -m venv .venv && .venv/bin/pip install -r requirements.txt  # 或按 pyproject 安装

# 环境
cp .env.example .env   # 填 DEEPSEEK_API_KEY（可不填，自动降级模板话术）

# systemd 服务
sudo tee /etc/systemd/system/clerk.service <<'EOF'
[Unit]
Description=YouPu Clerk workbench
After=network.target
[Service]
WorkingDirectory=/opt/clerk
Environment=CLERK_DB=/opt/clerk/data/clerk.db
ExecStart=/opt/clerk/.venv/bin/python -m uvicorn clerk.server:app --host 127.0.0.1 --port 8100
Restart=always
RestartSec=3
[Install]
WantedBy=multi-user.target
EOF
sudo systemctl enable --now clerk

# Caddy（自动 HTTPS）
sudo tee /etc/caddy/Caddyfile <<'EOF'
你的域名.com {
    reverse_proxy 127.0.0.1:8100
}
EOF
sudo systemctl reload caddy
```

## 3. 上线检查单（G4 验收）

- [ ] `https://你的域名/api/health` 返回 `status: ok`
- [ ] 首页打开 → 「看 60 秒演示」→ 老王剧本 6 步全部可点，判定与预期一致
- [ ] 手机浏览器同样可用（响应式）
- [ ] zh/en 切换无漏翻
- [ ] 真钱收款走通一笔（G3 之后补勾）
- [ ] 连续 24h 无重启（`systemctl status clerk` 看 uptime）
- [ ] SQLite 每日备份：`crontab -e` 加
      `0 4 * * * sqlite3 /opt/clerk/data/clerk.db ".backup '/opt/clerk/backups/clerk-$(date +\%F).db'"`

## 4. 备案来不及的备选路线（按优先级）

1. **借已备案域名**：家人/朋友名下已备案域名加一条解析 + 在其备案主体下加二级域名（需对方配合，最快 1 天）
2. **合作平台托管**：观猹（赛事合作方，pay.watcha.cn）等平台自带域名与收款，作品入驻其平台——同时顺手满足"智能收款套件"接入；代价是产品形态受平台约束
3. **海外服务器 + 无备案域名**：技术上可行且评委能访问，但支付宝签约回调域名是否接受海外站点**未验证**——必须先问组委会/开放平台客服再走这条路
