评委/买家/支付宝 → Cloudflare 无关 → Tailscale 中继/打洞 → 你家电脑 uvicorn(8100) → SQLite 真磁盘。
没有中间层改请求：JSON/POST/回调原样进出（已用 smoke+rehearsal 对着公网 URL 验证）。

## 2. 换网络/换地点

**无需任何操作**。身份绑机器不绑宽带：换 Wi-Fi、热点、运营商后 tailscaled 自动重连，
`zcc.tail408b90.ts.net` 一字不变。唯一要求：出站网络通（任何 NAT/CGNAT 都行，不用开路由器端口）。

## 3. 评审期（12/10-14）纪律清单

- [ ] 电源计划：接通电源时"睡眠=从不"（控制面板→电源选项）
- [ ] Windows 更新：设置→更新→**暂停 5 周**（覆盖评审期，防自动重启）
- [ ] tailscaled 服务：services.msc 确认 Tailscale 服务"自动(延迟启动)"（安装默认即是）
- [ ] uvicorn 自启：把启动命令放进 funnel-on.bat 同级脚本或任务计划（开机跑 `python -m uvicorn clerk.server:app --port 8100`）
- [ ] 每天早检：`python -m clerk.smoke https://zcc.tail408b90.ts.net`（30 秒）+ 看一眼桌面漏斗图标在线
- [ ] 应急预案：站挂了 → 评委仍有 Pages 预览站兜底；修复后 funnel-on 即恢复（域名不变，notify_url 不用改）

## 4. 支付宝回调接入

- `ALIPAY_NOTIFY_URL=https://zcc.tail408b90.ts.net/api/pay/notify`（.env 注入，重启生效）
- ts.net 证书由 Tailscale 自动签发续期（HTTPS ✅ 满足 notify_url 要求）
- 回调从支付宝境内服务器打向 ts.net 中继：若极端情况不通，**支付主链路不受影响**——
  订单状态机有 trade.query 轮询兜底（clerk/pay.py），notify 只是加速器
