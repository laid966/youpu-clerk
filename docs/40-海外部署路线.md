# 40 · 海外部署路线（Plan B：备案赶不上 12/9 时的正解）

> 触发条件：**今天还没提交 ICP 备案首发申请** → 首次备案 7-20 天，大概率晚于 12/9 提交截止。
> 本路线不需要备案：宿主在海外，支付宝 `notify_url` 只要求"公网 HTTPS"，文档无 ICP 要求。
> 仓库里已备好 `Dockerfile` / `.dockerignore` / `fly.toml`，照抄下面 8 步即可。

## 为什么是 fly.io

| 需求 | fly.io 给不给 |
|---|---|
| 持久磁盘（SQLite 必须活过重启） | ✅ volumes |
| 免费/极低价小机器 | ✅ shared-cpu-1x 约 $2-5/月 |
| 自动 HTTPS 域名 | ✅ `youpu-clerk.fly.dev` |
| 评审期常驻不缩容 | ✅ `auto_stop_machines=false`（fly.toml 已配） |
| 大陆可达 | ✅ hkg 区域延迟可接受（预览另有 GitHub Pages 兜底） |

## 八步

```bash
# 0 装 flyctl（一次性）
#    Windows: powershell -c "iwr https://fly.io/docs/windows/installer.ps1 -useb | iex" 或 winget install fly.io.flyctl
fly auth login

# 1 创建应用（名字全局唯一；被占就换）
fly apps create youpu-clerk --org personal

# 2 创建持久卷（SQLite 的家）
fly volumes create clerk_data --region hkg --size 1

# 3 密钥进 secrets（不进镜像不进仓库）
fly secrets set DEEPSEEK_API_KEY=*** \
  ALIPAY_APP_ID=... ALIPAY_PRIVATE_KEY=... ALIPAY_PUBLIC_KEY=... ALIPAY_SELLER_ID=... \
  ALIPAY_NOTIFY_URL=https://youpu-clerk.fly.dev/api/pay/notify \
  ALIPAY_RETURN_URL=https://youpu-clerk.fly.dev/?pay_return=1

# 4 部署（本地仓库根目录执行；构建用仓库里的 Dockerfile）
fly deploy

# 5 验收（本仓库两条门禁）
python -m clerk.smoke      https://youpu-clerk.fly.dev
python -m clerk.rehearsal  https://youpu-clerk.fly.dev

# 6 真钱（G3）：按 docs/38 走——沙箱先行，生产 ¥6.9 一单三侧取证
# 7 把正式站链接写进赛事提交材料与 docs/37 发布文案
# 8 评审期每日早检：docs/36（smoke + fly status + fly logs）
```

## 与 Plan A（境内+备案）的关系

- 备案批下来后**可以迁回境内**（延迟更低、评委体验更好）：数据 = 一个 SQLite 文件，
  `fly ssh console` 里 `sqlite3 /data/clerk.db .backup` 导出 → 境内服务器导入 → 改 notify_url → 完成。
  迁移窗口选评审期之外。
- 两条路线**代码零差异**：差异只在环境变量与宿主，这正是"凭证注入即切换"设计的回报。

## 诚实清单（海外路线的已知代价）

1. 大陆访问延迟 60-120ms（可接受；静态预览走 GitHub Pages 不经过它）
2. fly.dev 域名"看起来不像正式商业站"——决赛前若备案已批可换境内+自有域名
3. 月成本 $2-5（评审期常驻）；Plan A 境内轻量约 ¥50-100/月
4. 支付宝对海外域名回调**无文档禁止**，但属未证实假设——沙箱阶段先验证通知可达（docs/38 阶段 0 第 5 步会暴露问题）
