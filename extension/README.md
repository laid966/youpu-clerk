# 有谱掌柜 · Chrome 扩展（建议模式）

选中买家消息 → 浮动按钮 → 授权内的回复建议 → **你亲手复制、亲手发送** → 一键记台账。

## 安装（开发者模式加载，比赛阶段不上商店）

1. 电脑上启动工作台后端：
   ```
   .venv\Scripts\python.exe -m uvicorn clerk.server:app --port 8100
   ```
2. Chrome 打开 `chrome://extensions`，右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录（`extension/`）
4. 点扩展图标 → 「打开工作台」→ 在工作台里创建商品档案（扩展与网页**同一账户**，
   靠 URL 里的 token 打通）
5. 回到弹窗选择「当前商品」→ 保存

## 使用

- 在**任何网页**（闲鱼网页版、淘宝、微信网页版…）选中买家的一句话
- 点浮出的「谱 · 问掌柜」按钮（或右键菜单）
- 面板给出：决策徽章（还价 ¥379.05 / 可成交 / 守价 / 转人工）+ 规则依据 + 建议回复
- 「复制回复」→ 亲手粘贴发送 → 「已发送（记台账）」

## 设计立场（写给评委与商店审核）

| 立场 | 说明 |
|---|---|
| **划词触发，平台无关** | 不逆向任何平台 DOM/私有接口，不依赖闲鱼页面结构——平台改版不影响，本质是"店主自己的剪贴板助手" |
| **永不代替发送** | 源码中不存在自动发送能力（`tests/test_clerk_extension.py` 有红线测试盯着） |
| **零敏感权限** | manifest 只要 `contextMenus` + `storage`，**不申请 host_permissions**（后端 CORS 全开，跨域 fetch 即可）；不碰密码、不碰 cookie |
| **钱由程序算** | 扩展只是显示层：每个价格数字都来自工作台的授权引擎，前端与扩展都不做任何金额运算 |

## G1 之后的可选增强（当前不做）

若验证闲鱼网页版 IM 的 DOM 结构稳定可读，可加"自动监听新消息"增强层
（仍然只弹建议、不代发）。划词模式永远是兜底——所以产品不被 G1 结果绑架。

**G1 怎么验证（30 秒，不需要开发者工具）**：在闲鱼网页版的聊天页面打开扩展弹窗 →
点「🩺 页面诊断」→ 把结果复制发给开发者。诊断只读地统计聊天 DOM 的候选选择器命中数
与一个结构样本，**不读取任何消息内容**——它回答的问题是"自动监听层能不能做、选择器怎么写"。

## 已知边界

- `content.js` 的 `<all_urls>` 匹配是为了"任意平台可用"；上商店时按审核意见可收窄到具体域名
- 移动端浏览器不适用（无扩展生态）——手机卖家用工作台网页的粘贴模式
